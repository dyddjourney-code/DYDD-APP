# Sandbox assessment timing core contract

Sandbox only. DB eligibility `public.dydd_assessment_eligibility(p_user_id uuid,p_assessment_type text,p_owner_exemption boolean default false,p_now timestamptz default now())` returns JSON: allowed,owner,nextEligible,previousAttemptId,previousCompletedAt,reason,grantId,legacyOverrideId. Trusted service-role only; account email/history derived from auth.users, not caller email.

`public.dydd_assert_assessment_completion(p_user_id uuid,p_assessment_type text,p_owner_exemption boolean default false)` returns same JSON after taking shared account/type xact advisory lock `hashtextextended('assessment-timing:'||user_id||':'||assessment_type,0)`. Completion writers must call it BEFORE successful response/attempt insert, and consume selected grant `used_at=now()` in SAME transaction after insert. Exceptions roll back both. Timed keys designid/spiritual_gifts/fruitful_self. It does not consume permits on draft/eligibility reads.

Core owns atomic save_designid_attempt and save_spiritual_gifts_attempt. FruitLife lane owns self completion transaction/round limits/report quotas. Core eligibility for fruitful_self calls the Fruitful completion helper over successful self-only responses plus linked imported completed SELF_ONLY snapshots, excluding native derived report generations; previousCompletionId records the native response UUID before a PDF snapshot exists. Legacy DesignID overrides preserved. `dydd_assessment_retake_grants` owned by request lane; core reads id,user_id,assessment_type,expires_at,used_at and consumes used_at. Snapshot scores retain grant/request audit link.
