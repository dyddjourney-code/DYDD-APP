# Contact support foundation

- Migration: `supabase/migrations/20261023204446_contact_support_intake.sql` (not applied by implementing agent).
- Public page: `/contact`. POST `/api/contact`, same-origin JSON `{name,email,subject,message,website?}`. Successful durable save: 201 `{received:true,reference:uuid}`. Honeypot returns generic 201 without writing. Validation 400, cross-origin or missing Origin 403, rate limit 429, unavailable storage 503. No email or forwarding.
- Admin page: `/admin/support`. GET `/api/admin/support?status=new|in_progress|resolved&page=0`, 25 rows with `hasMore`. PATCH same endpoint `{id,status,revision}`; optimistic revision check returns 409 for stale edits. Every route requires live Supabase `getUser()` plus existing `isDyddAdminEmail`; preview cookies/queries do not grant access.
- Tables are service-role only, RLS enabled, no anon/authenticated grants or policies. All access is server mediated. Never add public select policies for support messages.
- Atomic RPC `submit_support_request` returns UUID or null if throttled; hourly limits: 3 per normalized-email hash, 15 per network hash. HMAC hashing uses the existing server-only service key. Trusts only Vercel's overwritten `x-vercel-forwarded-for` when `VERCEL=1`; self-hosted deployments share a conservative network bucket. No raw IP retention. Rate counters expire and are pruned after two hours. Fixed-window limits can allow adjacent-window bursts; concurrency cannot bypass each window's counters.
- API responses are private/no-store. Contact/admin HTML no-store headers are configured separately in Next headers. Messages are rendered as escaped text, not HTML. No response time or outbound reply promised.
- Tests: `node tests/contact-support.cjs` and `node tests/contact-support-auth.cjs` (passed); browser: `CONTACT_BASE=http://localhost:<parent-server> node tests/contact-support-browser.mjs`. Browser success/error states use intercepted intake; actual sandbox persistence and DB concurrency use `tests/contact-support-sandbox.mjs` after migration, explicitly sandbox-gated.
