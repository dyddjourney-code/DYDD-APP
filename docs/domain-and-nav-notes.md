# Domain And Navigation Notes

## Domain Options

Best early options:

- `school.discoverdivine.design`
- `academy.discoverdivine.design`
- `learn.discoverdivine.design`

Recommendation: start with `school.discoverdivine.design`.

Reason: it is clear, expandable beyond DesignID, and does not force a new purchased domain before the concept is proven.

## Existing DYDD Site Navigation

Add a small utility bar above the main navigation on the main DYDD site.

Possible copy:

- `DYDD School`
- `Sign in`
- `Start the DesignID Class`

Early version:

- `DYDD School` links to the school landing page.
- `Sign in` links to the Supabase auth route.
- `Start the DesignID Class` links to checkout or enrollment.

## Later

Once Stripe and course access are solid, the main site can promote courses more directly with a top-level navigation item.
