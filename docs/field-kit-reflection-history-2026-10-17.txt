Architecture
- Canonical question catalog: lib/reflections/catalog.ts. Exact course reflection
  prompts; DesignID Reflect/Notice/Respond prompts come from its original HTML.
  Journey lesson, CARE/workbook, Pathfinder and supplemental chapter prompts
  share stable IDs. Every question appears, even when unanswered.
- Each account has independently dated reflection_rounds. Each round freezes the
  actual questions and versions, with an optional owned assessment-report link.
- reflection_entries is append-only. Each edit adds a revision; it does not
  replace an earlier answer. An expected revision detects stale browser tabs.
  PostgreSQL advisory locking makes per-question saves atomic. PT409 is used
  for an application-level stale-edit conflict (not serialization retry 40001).
- Round creation requires existing assessment/report/course access; DesignPD
  retains its independent existing report access checks. Reading one's own
  history does not require repurchasing. Preview sessions cannot write.
- Both tables enforce owner-only RLS. Entries cannot be updated/deleted by the
  authenticated role. Round update grants are limited to lesson position and
  updated_at; user_id and immutable question snapshots cannot be reassigned.
- Only the newest round is editable in the UI; earlier rounds are readable.
  Reopening a course continues its current round. A new round requires an
  explicit click, optionally linked to one of the account's reports.
- Current course position saves to the round/account, not just browser storage.
  Existing browser position keys remain as a fallback before a round exists.

Surfaces
- /field-kit: all dated reports, no longer just the latest non-FruitLife report;
  reports and Course Reflections beside each other in each named experience.
- /field-kit/reflections/[courseSlug]: readable question-and-answer workbook;
  deliberate editing mode, dated rounds, previous answers and revision history.
- Actual course players, standalone lesson routes and supplementary Journey
  workbook fields use the same reflection records, not separate copies.
- Niche builder: modal Field Kit side panel, experience and dated-round browsing,
  source-attributed insight insertion, and an account-saved working declaration.
  Report collection opens in another tab so the niche draft remains in place.
- Existing FruitLife assessment tracking and dedicated access route retained.
